# Changelog

## 0.1.0 (unreleased)

- First public version. Lifted from a private per-repo extension and renamed.
- Sidebar tree and board page, one Copy button per entry, `{slots}` with
  values remembered per workspace, live reload of `docs/pegboard.md`.
- Pages: `page:` per entry, `pages:` in the preamble for order, the same entry
  on several pages with shared slot values.
- Starter file with two meta prompts ("add an entry for what I paste next",
  "propose the first ten entries") and a "Pegboard: Add entry" command.
